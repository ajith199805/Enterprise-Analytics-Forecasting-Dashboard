# Enterprise Analytics & Forecasting Dashboard

An end-to-end Power BI project built to explore what a full enterprise-style analytics platform looks like in practice — covering revenue, customer behavior, retention, and forward-looking financial forecasting in a single connected report.

## 📌 Overview

This is a personal/portfolio project built to practice designing a multi-page BI solution the way it would be structured for a real business: a proper star-schema data model underneath, DAX-driven KPIs and time intelligence, and a forecasting layer on top of historical data.

## 📊 Dashboard Pages

| Page | What it covers |

## 🧱 Data Model

- Built on a **star-schema** design with fact and dimension tables, optimized for reporting performance rather than transactional use
- Relationships modeled to support drill-down and cross-filtering across all 7 pages

---

## 🧮 Key Techniques Used

- **DAX time-intelligence measures** for period-over-period and trend calculations
- **Forecasting logic** to project key metrics forward based on historical patterns
- **19 interactive slicers** enabling self-serve, cross-filtered exploration without needing analyst support
- **27 KPI card visuals** for at-a-glance metric tracking
- Visual variety: line charts, clustered column/bar charts, a scatter chart, 100%-stacked charts, a donut chart, and a filled map
